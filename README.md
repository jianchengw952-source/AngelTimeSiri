# 天使时光siri (AngelTimeSiri)

基于 iOS 越狱平台的深度 AI 视讯对讲与全双工实时通话插件（锁屏优化与启动连接优化版本）。

## 核心特性
1. **官方级 Gemini Live 实时语音通话**：全双工低延迟对讲、双向语音转文字（STT）实时上屏。
2. **毫秒级自然插话打断 (Barge-In)**：支持用户开口随时打断 AI 回答，双闭环切断旧音频。
3. **640p 流式摄像头视觉理解**：实时视讯模式边看边聊。
4. **全屏三模交互界面**：支持实时通话、实时视讯与纯文本模式。
5. **锁屏与启动优化**：深度针对锁屏状态唤醒、网络连接握手与启动流程进行性能调优。
